## Project Overview

* **Course:** BIT 2118 – Scientific Computing
* **Institution:** Mount Kenya University (Thika Main Campus)
* **Scope:** Numerical linear algebra, root finding, interpolation, curve fitting, numerical calculus, ordinary differential equations (ODEs), constrained optimization, and Monte Carlo simulations.
* **Deliverables:** Base algorithmic implementations, parameter sensitivity experiments, real-world case adaptations, generated plots, and per-task technical reports.
